# Scorned Wilderness (Kuldra raid) - optimal run path to beat 6:50.00

Built 2026-11-03 from frame-timed record runs. Every time below was read off contact sheets (1 frame / 2 s) and refined with 0.2 s strips (about +-0.3 s, about +-1 s on fuzzy visual checkpoints). Run time = video time - timer offset. The splits are the given LiveSplit marks.

**Patch status.** The 6:50 (TexasPete, recorded 2026-10-14, 1.0.0.6-era route) uses strats that have since been patched: the old Keep skip (blue rock climb, patched in 1.0.1) and the Thane-less wall climb (inferred patched, because 1.0.1 runners need the Thane air charge). It also uses the windstep up the blocks to Kuldra (patched in 1.0.1.2 per Nanobit). Nanobit 7:01 (1.0.1/1.0.1.1) and SamF (1.0.1) also use the block windstep in the Sanctum. **So no existing run is legal end-to-end on 1.0.1.2. The target route below is built only from pieces that are still valid on 1.0.1.2, and anything that is unverified is flagged.**
