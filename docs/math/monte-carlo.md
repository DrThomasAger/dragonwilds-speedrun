# Monte Carlo of full raid times

_Generated by `scripts/analysis/docs.mjs` from `data/kb/analysis/*.json` (2026-11-03). Runpath: `D:\labyrinth\Github\JaGeX\dragonwilds-speedrun\data\kb\runpath.json`._

## Plain English

We play the raid 100,000 times on paper. Every simulated run draws each split from the profile's distribution and flips a weighted coin for every skip on the line. Counting how many runs finish under 6:50.00 gives the probability.

## Algorithm

```
for i in 1..N:
  t = 0
  for split k in 1..5:
    (mu, sigma) = posterior draw (user profiles) or the fixed calibrated values
    t += c_k + exp(mu + sigma·Z) + delta_v + delta_sd_v·Z'
    for each skip j on the line: if U ≥ p_j: t += loss_j; if U' < fatal_j: run dies
  record t (or DNF)
P(beat) = #(finished and t < 410) / N        standard error = sqrt(P(1 − P)/N)
```

**Common random numbers.** Every uniform comes from a counter-based hash of `(seed, run i, stream)`. Two scenarios that differ only in one parameter (one skip's rate, one route line) see exactly the same luck everywhere else. Their *difference* is then estimated with far less noise than either value on its own. The route optimiser and the practice ranking rely on this.
