## Plain English

**Sum of best (SOB)** adds up the fastest version of each split anyone has shown. It is a ceiling, not a forecast: it takes the luckiest split from each run and assumes they all happen together. The calibration (segment-distributions.md) turns it into a forecast. Nanobit's SOB 6:51 vs PB 7:01.97 after 177 attempts is what pins down how much luck a PB contains.

## Formulas

```
SOB           = Σ_k min over runs r of T_{r,k}
composite(A)  = Σ_k min over runs r in A of T_{r,k}
time on table = T_{r,k} − min over runs of T_{·,k}
target pace   = runpath target per piece (measured, 6:48.10)
```
